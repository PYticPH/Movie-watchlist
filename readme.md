#🎬 Movie Watchlist (API‑Focused)

A simple, web application to search for movies and build a personal watchlist. This project is designed to practice and demonstrate **API handling** – from fetching data to managing state – with a clear path toward integrating a real movie database API.

## ✨ Features

*   **Search Movies:** Find movies by title.
*   **Add to Watchlist:** Easily add movies from search results to your personal watchlist.
*   **Manage Watchlist:** View all saved movies on a dedicated watchlist page.
*   **Remove from Watchlist:** Remove movies when you're done.
*   **Persistent Storage:** Your watchlist is saved in the browser's local storage.
*   **Clean & Responsive UI:** A visually appealing, mobile‑friendly interface.

## 🛠️ Technologies Used

***HTML5 & CSS3** – Structure and styling.
*   **JavaScript (ES6+)** – All application logic, DOM manipulation, and state management.
*   **Local Storage API** – For data persistence (used as a placeholder until a real API is integrated).
*   **API Handling Concepts** – The code is structured to easily swap local data with asynchronous fetch calls and data transformation, making it an ideal foundation for learning and implementing API integration.

## 🚀 How to Use

This is a static front‑end application, so getting started is simple.

### Prerequisites
*   A modern web browser.

### Installation & Setup

1.  **Clone the repository**
    ```bash
    git clone https://github.com/PYticPH/Movie-watchlist.git
    ```

2. Navigate to the project directory
   ```bash
      cd Movie-watchlist
      Open the application
    ```

3. Open index.html in your preferred browser.
   No build steps or server are required.
